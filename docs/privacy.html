プライバシーポリシー

制定：2026年11月21日 ／ 最終改定日：2026年11月22日

1. 基本方針

OurHours（以下「本アプリ」）は、パートナー同士が一緒に過ごした時間や思い出を安心して記録・共有できるよう、プライバシー保護を最優先に設計されています。開発者自身が運営する独自サーバーでユーザーの記録・写真・位置情報を収集・閲覧することはありません。

2. 取り扱うデータと利用目的

  • Bluetooth 近接記録（日時・継続時間）：ペア設定した相手の端末と近くにいる時間帯を自動記録・集計するために使用します。
  • 位置滞在ログ（任意・デフォルト有効／設定でオフ可能）：Bluetooth が届きにくいバックグラウンド環境での取りこぼしを防ぐため、おおよその滞在履歴をペア間でのみ突き合わせて「一緒にいた時間」の補完に使用します。現在地のリアルタイム共有や、滞在ログを地図画面に表示することは一切ありません。直近の滞在座標ログは最大14日分で自動削除されます。
  • ユーザーが入力する記録・予定・思い出・きせかえ設定：手動で追加・編集した時間記録、1日のひとことメモ、記念日・誕生日、旅行やデートの予定（やりたいこと・持ち物リスト）、シャボン玉のきせかえ設定をカレンダー・ホーム表示およびパートナー間同期のために保存します。
  • 写真・動画・場所タグ：ユーザーが明示的に追加した写真・動画・撮影地情報や場所タグを、アルバムおよび「思い出マップ」に表示し、パートナー間で安全に共有するために使用します。

3. エンドツーエンド暗号化（E2EE）と保存場所

ペア設定時に QR コードまたは招待 URL で交換する 256-bit の共有鍵を用い、Apple CryptoKit（AES-GCM＋HKDF）によって端末内で記録・予定・写真・動画を暗号化したうえで同期を行います。

同期データはユーザー自身の Apple iCloud Private Database（CKShare によるペア専用共有ゾーン）およびオフライン移行用の暗号化ブートストラップ領域を通じて送受信されます。復号鍵はペアの端末内の Keychain にのみ保管されるため、開発者や第三者が記録内容や写真・場所データを復号・閲覧することはできません。

4. 第三者提供・広告・解析ツール

本アプリは、広告 SDK、トラッキング SDK、行動解析ツールを一切組み込んでおらず、ユーザーデータを第三者に販売・共有・提供することはありません（アプリ間トラッキングも行いません）。

5. データの削除・管理

  • アプリ内の「設定」→「ペア連携を解除」を実行すると、以降の認証・同期が即座に停止し、iCloud 上の共有ゾーン／共有レコードの削除が行われます。
  • 追加した写真・動画・場所タグ・予定はアプリ内から個別に削除でき、端末内の履歴は「設定」またはアプリのアンインストールによって削除できます。

Privacy Policy Summary (English)

OurHours is built to let couples record shared time and memories privately. All shared encounter logs, plans, daily memos, photos/videos, place tags, bubble customization profiles, and optional background proximity logs (retained up to 14 days for raw logs, never shown on the Memory Map or shared as live location) are encrypted end-to-end on-device using Apple CryptoKit (AES-GCM with HKDF-derived keys from a QR-exchanged 256-bit shared secret) and synced through your own Apple iCloud Private Database (CKShare shared zone).

The Memory Map tab shows only photos and place tags you explicitly added. The developer has no access to your decryption keys or personal data, uses no third-party analytics or ad SDKs, and does not track users across apps or websites. You can stop syncing and remove cloud records at any time from Settings → Unpair, or by deleting the app.
